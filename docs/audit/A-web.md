# Area A report (web, internet-facing). Decision override: user chose ONE token hardened (no separate hook token) -> A9 "hook token" is NOT adopted; webhook keeps the master token but gets the A1 gate/limiter. Everything else stands.
A1 BLOCKER only POST /login counts wrong tokens (auth.rs:219, :258; routes.rs:554 hook limiter after auth counts deliveries). CSRF (csrf.rs:206-214) runs BEFORE auth -> wrong-bearer POST gets 403, right bearer 415/400: yes/no oracle. Fix: one auth::gate layer before host/csrf for every non-public path incl. hook; limit check before compare; failures keyed by client ip (A3); 429+Retry-After. Tests: 10 wrong bearers to GET /api/v1/runs, POST /exports/clear, POST /hooks/dispatcharr -> 11th 429 even with correct token; wrong-bearer POST w/o csrf -> 401/429 never 403; one counter per client across routes.
A2 BLOCKER no min token length (config.rs:54-82, 1377-1384, 2494). Fix: validate() error + serve refuses when resolved token < 32 bytes and bind non-loopback or trusted_proxies set; same on save_host_settings reload (routes.rs:955). Tests.
A3 BLOCKER no client-IP behind proxy (main.rs:393-403, routes.rs:232/549 key on ConnectInfo). Attacker with spoofed XFF locks operator out; record_success clears shared bucket. Fix: [server] trusted_proxies CIDR list; client_ip(&Request): honour XFF (rightmost non-trusted) or X-Real-IP only when peer in trusted CIDR; IPv6 keyed by /64; cap limiter map, prune not O(n) per call (auth.rs:61-73). Tests: table tests + router test.
A4 BLOCKER tokenless loopback + proxy on same host = open (auth.rs:125-132, main.rs:326, host.rs:61-80 allows Host 127.0.0.1). Fix: any request carrying Forwarded/X-Forwarded-*/X-Real-IP is non-loopback -> 401/403 when tokenless; non-empty trusted_proxies implies requires_token at startup. Tests.
A5 SHOULD cookie is raw master token, no Secure, logout doesn't invalidate (routes.rs:260-262, 273-280, auth.rs:150). Fix: random session id (csrf::generate_token) in memory w/ idle 12h/absolute 7d; cookie crosstalk_session HttpOnly SameSite=Strict + Secure when X-Forwarded-Proto https from trusted proxy or server.secure_cookies; logout removes session; Authorization header only carries master token. Tests.
A6 SHOULD Origin/Host compare breaks behind Host-rewriting proxy and ignores scheme/port (host.rs:39-55). Fix: compare full origin vs optional server.public_url, else trusted X-Forwarded-Proto/Host, else Host. Tests.
A7 SHOULD no HSTS, no Cache-Control no-store (security.rs:32-52). Fix: no-store on all but /static/* (public, max-age); HSTS when https via trusted proxy or server.hsts; optional COOP/Permissions-Policy. Test.
A8 SHOULD CSRF buffers 1MB of every unauthenticated POST (csrf.rs:206); login/hook 2MB default; no timeouts/concurrency limit. Fix: gate before buffering; per-route DefaultBodyLimit (/login 4KiB, hook 64KiB, settings 256KiB, rest 64KiB); TimeoutLayer + ConcurrencyLimitLayer. Tests.
A9 SKIPPED by decision (one token). Keep note in docs. (Later adopted: see the status table.)
A10 SHOULD webhook debounce never settles under steady deliveries (hooks.rs:408, 434-443). Fix: hooks.max_settle_secs default 5x debounce cap 15min; fire_at=min(last+debounce, first+max_settle). Paused-time tokio test.
A11 SHOULD hook logs every field key at info (routes.rs:579). Fix: field_count + first 10 keys truncated 64B. Test.
NITs: N1 tokens_match length early-return (auth.rs:174-185) -> compare SHA-256 digests constant time; N2 check-then-record race -> atomic try_attempt; N3 token chars in cookie (moot with A5); N4 wrong token on /login returns 200 -> 401; N5 CSRF only checks POST -> exempt only GET/HEAD/OPTIONS; N6 CSRF token daemon-lifetime shared -> HMAC(session_id) after A5; N7 pre-auth error bodies generic; N8 202 echoes event name -> sanitize; N9 resolve_secret doc vs precedence (env should win, see C-S3); N10 bind.starts_with("127.") -> parse IpAddr; N11 server-side 256 char cap on action input.
